# CodeJet Conversion Funnel

Do not map plain video starts, page views or `codejet_inquiry_accepted` to the campaign's primary Ads conversion. Use only **`codejet_demo_engaged_lead`** and set up the corresponding GTM Custom Event trigger and manual Google Ads Conversion Tracking tag. See [GOOGLE_ADS_DEMO_LEAD_SETUP.md](GOOGLE_ADS_DEMO_LEAD_SETUP.md).

Production form and sales mail delivery are separate from ad attribution; qualification never blocks genuine inquiries. The client reports played time ranges, not verified human attention.
